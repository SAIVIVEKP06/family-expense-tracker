# Family Expense Tracker

A simple and responsive web application for managing and tracking family expenses.

## Live Demo

[View Live Demo](https://saivivekp06.github.io/family-expense-tracker/).

## Project Overview

Family Expense Tracker helps users record and manage their daily family expenses in one place. Users can add expenses with details such as expense name, amount, family member, category, and date.

The application also provides a quick summary of total expenses, monthly expenses, and the number of transactions.

## Features

- Add new expenses
- Track expense amount
- Select family member
- Categorize expenses
- Select expense date
- View total expenses
- View current month's expenses
- View transaction count
- Filter expenses by category
- Delete expenses
- Store data using browser LocalStorage
- Responsive design for different screen sizes

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- GitHub Pages

## How It Works

1. Enter the expense name and amount.
2. Select the family member.
3. Select an expense category.
4. Choose the date.
5. Click the "Add Expense" button.
6. The expense is added to the recent expenses list.
7. The summary cards automatically update.
8. Expenses can be filtered by category or deleted when required.
